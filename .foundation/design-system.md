# Design System
## Версия 1

---

## Источники истины

- Этот документ — правила визуального языка OSA.
- Код UI (`app/page.js`, `app/components/`, `app/globals.css`) — текущая реализация; при расхождении с утверждённым Design System приоритет имеет утверждённый Design System после явного решения человека.
- Логотип: `public/logo.png`.

На момент синхронизации документации формальная дизайн-система OSA **не была утверждена** как отдельный закон. Ниже зафиксировано только то, что можно опереть на существующие факты; остальное помечено.

---

## 1. Характер продукта

Профессиональный инструмент дизайнера интерьера: спокойный, ясный, ориентированный на решение задачи спецификации, без «магазинной» витрины как главной идеи.

[Требует дальнейшего заполнения] Тон голоса UI, moodboard, референсы бренда.
